{% comment %} Переключатель языка для административной панели. Разметка вынесена отдельно, потому что вставляется в двух местах: * блок ``branding`` — для страницы входа (там ``nav-global`` пуст); * блок ``nav-global`` — для остальных страниц панели. Ссылки ведут на маршрут ``core:set_language`` с возвратом на текущий адрес (``?next=``), а выбор запоминается в сессии — поэтому дальше панель остаётся на выбранном языке. Параметр ``?lang=`` в самом адресе здесь не годится: в списках панели Django считает неизвестный параметр фильтром и отвечает лишним перенаправлением. {% endcomment %}
