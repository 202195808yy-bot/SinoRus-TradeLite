## Описание страниц


### M0. Общие страницы / 公共页面

#### `/` — Главная страница / 首页

- **Имя маршрута:** `index`
- **Представление:** `portal.views.index_view`
- **Режим доступа:** Общедоступная
- **Назначение:** 向未登录访客与已登录用户展示平台定位、核心能力与当前待办概览。
- **Основное содержание:** 平台一句话定位、四类核心能力卡片、中俄贸易背景数据摘要、登录/注册入口；已登录时追加今日待办、异常订单、临期证书三张摘要卡。

#### `/about/` — О платформе / 关于平台

- **Имя маршрута:** `about`
- **Представление:** `portal.views.about_view`
- **Режим доступа:** Общедоступная
- **Назначение:** 说明平台所处的产业链位置、四条业务边界与服务对象。
- **Основное содержание:** 平台定位（贸易协同层）、不做的四件事（资金业务、报关代理、合规结论判定、无关个人信息采集）、三类服务对象。

#### `/help/` — Справка / 帮助与使用指南

- **Имя маршрута:** `help`
- **Представление:** `portal.views.help_view`
- **Режим доступа:** Общедоступная
- **Назначение:** 提供按角色划分的操作指引与常见问题解答。
- **Основное содержание:** 按角色（中方贸易商、中方业务员、俄方合作方、货代操作员）分类的操作步骤、术语表、常见问题。

#### `/accounts/login/` — Вход в систему / 登录

- **Имя маршрута:** `login`
- **Представление:** `portal.views.login_view`
- **Режим доступа:** Общедоступная
- **Назначение:** 校验用户身份并建立登录会话。
- **Основное содержание:** 账号与密码输入、记住登录状态、验证码登录切换、忘记密码入口；登录失败给出明确原因与剩余尝试次数。

#### `/accounts/register/` — Регистрация / 注册

- **Имя маршрута:** `register`
- **Представление:** `portal.views.register_view`
- **Режим доступа:** Общедоступная
- **Назначение:** 创建个人账号并绑定所属企业主体。
- **Основное содержание:** 手机号与邮箱注册（支持中国 +86 与俄罗斯 +7 区号）、密码强度校验、验证码倒计时、企业主体关联入口。

#### `/accounts/logout/` — Выход из системы / 退出登录

- **Имя маршрута:** `logout`
- **Представление:** `portal.views.logout_view`
- **Режим доступа:** Требуется вход
- **Назначение:** 结束当前会话并清理本地登录态。
- **Основное содержание:** 退出确认提示；退出后跳转至首页。

### M4. Заказы / 订单管理

- **Представление:** `portal.views.order_list_view`
- **Режим доступа:** Требуется вход
- **Назначение:** 按状态、通道与时间检索订单，快速定位异常与超期订单。
- **Основное содержание:** 卡片化列表（订单号、对方企业、当前状态标签、关键时间、下一步动作）、状态筛选、异常订单置顶、导出入口。
